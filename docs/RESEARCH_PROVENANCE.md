# Research provenance

This project began as an academic exercise and was later reconstructed as independently written,
testable research software. The project records state that the research design was locked before
the private held-out evaluation. Subsequent corrections and descriptive extensions are recorded in
`docs/PREREGISTRATION_AMENDMENTS.md`.

The complete historical audit trail is retained separately and is not part of this distribution.
This repository starts from a curated snapshot, so its Git history does not independently establish
the earlier chronology.

No empirical rows, restricted input hashes, source-derived results, or qualitative empirical
outcomes are included. Readers can inspect the methodology, implementation, tests, synthetic
demonstration, preregistration, and amendments. Reproducing the private empirical evaluation
requires separately authorised access to the original source files.
