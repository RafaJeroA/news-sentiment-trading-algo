# Synthetic schema example

`schema-example.csv` is a small, independently authored example of the input schema. It contains
no empirical source rows and is covered by the repository's MIT License.

The four rows support parser and schema demonstrations only; they are not enough to run the
preregistered walk-forward experiment. Use `news-sentiment-trading synthetic-demo` for a complete
deterministic example. The fictional `SYNTH` label is not part of the empirical universe.
